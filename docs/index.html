Strongly encrypted text in your own Google Docs

Passwords, recovery codes and private notes, encrypted in your browser before Google sees them. With an optional decoy password.

Set up your copy Read the code

Free and open source. No account, no server, no tracking.

Google stores only ciphertext

Your text is encrypted on your device with AES-256-GCM. Neither Google nor anyone else can read it without the password.

Nobody in the middle

There is no DocLock service. You run your own copy, connected to your own Google account.

Small enough to read

About 2,400 lines of plain HTML, CSS and JavaScript. No libraries, no build step: What you read is what runs.

A plain doc that only you can read

  1. Open a Google Doc

    Paste its link, or create a new one.

  2. Type its password

    Each doc has its own. It is never sent or stored.

  3. Edit, save, lock

    Every save is encrypted again and checked. Markdown formatting included.

A second password, for the day someone forces you to unlock

The decoy password opens a harmless text instead of yours. The doc does not show whether it has one.

Get started

About 10 minutes, once. You need a Google account and any static HTTPS host. Free ones work.

  1. Host the app/ folder

    On GitHub Pages, Cloudflare Pages, Netlify or your own server.

  2. Open it and click Set up

    A guide takes you through Google Cloud one step at a time and makes your config.js.

  3. Upload config.js

    Next to index.html. DocLock checks it and is ready.

Questions

Can Google read my secrets?

No. Google receives and stores only a block of random-looking characters. It does see the doc's title and when you saved.

Can the DocLock author see them?

No. There is no DocLock server and no DocLock account. Nothing passes through the author.

What if I forget the password?

Then nobody can recover the text, not even you. There is no reset and no back door.

Has it been audited?

No. It is one person's project with no independent audit. It is small enough to read in full, and the encryption uses only the browser's built-in Web Crypto. Reviews are welcome.

What if DocLock disappears?

Your text stays readable. The format is documented, and a few lines of Python decrypt a doc without DocLock.

Why do I have to host my own copy?

A web page is only as trustworthy as whoever serves it. With your own copy, that is you.
